# Task: CPA 智能路由与精简界面
Created: 2026-07-30
Status: complete
Execution Mode: solo

## 目标

- 将 CPA 智能路由作为桌面应用的主启动路径：点击“智能启动 Codex”后启动官方 Codex CLI，并只对本次启动注入本地 CPA provider 配置，不把 CPA 描述成 Codex 官方账号选择能力。
- 保留现有账号切换作为兼容直连路径；两种路径只共享账号目录、别名和额度视图，不共享可并发写入的凭据文件，避免 OAuth 刷新互相覆盖。
- 默认将账号加入智能池，允许显式排除；CPA 不可用时明确报错，不静默回退直连。
- 按已确认的精简 UI 实现菜单栏主界面、今日消耗浮层和单一管理窗口；暂不增加自定义分组。
- 保持现有额度与 Token 统计口径不变，只优化菜单打开全量刷新、CPA 事件增量刷新以及文件扫描的互斥与去重。
- 通过隔离环境中的 Zig、Swift 测试和构建验证，完成后按项目交付规则准备桌面安装与提交。
